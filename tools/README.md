# Инструменты: примеры предложений и шрифты

Собирают `data/sentences-1…6.json` (примеры к каждому знаку) и `fonts/`. Нужен только Node.js 18+.

```
cd tools
npm install          # один раз: pinyin-pro (пиньинь) и seek-bzip (распаковка выгрузок)
npm run download     # выгрузки Tatoeba + словарь HSK в tools/.cache (~45 МБ, распакованно ~250 МБ)
npm run select       # отбор предложений Tatoeba → sentences/picks.json
npm run build        # сборка data/sentences-N.json + списки дел в .cache/todo/
npm run show -- 好 学 会    # посмотреть, что получилось у знаков
```

`download` нужен один раз (и когда хотите свежую Tatoeba). `select` — когда меняли правила или
хотите подобрать замены отбракованным; `build` — после любой правки в `sentences/`.

## Правила отбора

У каждого знака 2–3 предложения, не длиннее 12 иероглифов, только китайские знаки и пунктуация.

- **HSK 1** — по урокам HSK Standard Course 1 (списки уроков берутся из `index.html`):
  пример к знаку из урока N состоит только из знаков уроков 1…N.
- **HSK 2–6** — все слова из HSK уровня знака или ниже: слово из HSK 2.0 этого уровня, либо
  слово из HSK 3.0 этого уровня, все иероглифы которого уже есть в приложении к этому уровню
  (в списке HSK 2.0 нет даже 天, 一些, 春天).
- Приоритет у предложений Tatoeba с русским переводом, затем Tatoeba с английским (перевод наш),
  затем составленные нами (в приложении помечены «составлено»).
- Уже отобранные предложения при повторном `select` сохраняются, чтобы не терять переводы.

## Что лежит в `sentences/` (это наши данные, они в git)

| Файл | Формат | Зачем |
|---|---|---|
| `picks.json` | — | результат `select`, не править руками |
| `translations/*.tsv` | `id⇥русский перевод` | переводы предложений Tatoeba, у которых нет русского |
| | `id⇥SKIP` | предложение Tatoeba не использовать (грубое, кривое, с именами…) |
| `composed/*.tsv` | `знак⇥предложение⇥перевод` | свои предложения; `!знак` в начале — показать первым |
| `exclude.txt` | одно предложение на строку | никогда не использовать (например, реплики из учебника) — **файл локальный, в git не попадает** |

Строки, начинающиеся с `#`, — комментарии. Номер `id` — это номер на tatoeba.org.

`exclude.txt` указан в `.gitignore`: в нём реплики из учебника HSK Standard Course, которым не место
в публичном репозитории. Он есть только на том компьютере, где его создали. Без него сборка тоже
работает, но фразы из учебника могут вернуться в примеры — перед `select`/`build` на новом
компьютере создайте файл заново (формат — одна фраза на строку, `#` — комментарий).

## Как дополнять

1. `npm run build` — в конце он пишет, сколько осталось дел, и кладёт списки в `.cache/todo/`:
   - `translate-*.tsv` — предложения без перевода (`id⇥китайский⇥английский`): переведите и
     допишите `id⇥перевод` в новый файл `translations/NN.tsv` (или `id⇥SKIP`);
   - `compose-*.tsv` — знаки, где меньше 2 примеров: в подсказке для HSK 1 перечислены
     разрешённые знаки урока, для HSK 2–6 — подходящие слова. Допишите строки в `composed/`.
2. Снова `npm run build`. Составленные предложения, которые не прошли правила, он перечислит
   с причиной («урок 3: 请 not yet taught», «level 5 > 3», «13 han» …).
   `node build.mjs --prune` удалит такие строки из `composed/`.
3. Не понравился пример из Tatoeba — `npm run show -- 知` покажет его `#id`;
   допишите `id⇥SKIP` в `translations/`, затем по очереди `npm run select` и `npm run build`.
4. Проверьте шрифт: `npm run font-gap`. Если появились новые знаки — `npm run fonts`, потом
   сверить список шрифтов в `sw.js` и поднять `SHELL_VERSION`.

Пиньинь ставит pinyin-pro; многочтения отдельно стоящих 得, 地, 只, 长, 为, 了, 着, 还
поправляются правилами в `build.mjs` (функция `polyphone`). Тоны 一 и 不 записываются так, как
произносятся (`yìdiǎnr`, `bú huì`). Лёгкий тон, как в учебнике (`xuésheng`, `péngyou`, `zhège`),
берётся из словаря HSK. Слова пишутся слитно по словарю; исключения — в `build.mjs`:
`NO_GROUP` (всегда раздельно: `bú kèqi`, `méi guānxi`) и `CLAUSE_START_ONLY` (слитно только в
начале фразы: `Zàishuō, …`, но `bú huì zài shuō`).
