# Только знаки уроков 1…N (проверяет `npm run speech`). Диалоги учебника не копировать.
#
# = N              урок
# == Д: название   диалог; реплики «A: китайский | перевод», «B: …»
# == Ф: название   опорная схема: Q — вопрос, A — варианты ответа (2–3),
#                  R — что заменять, S — на что («S: слово | перевод»)
# Имена: 美美 (Мэймэй), 国生 (Гошэн), 关老师, 谢老师, 谢先生 — пиньинь для них задан в speech.mjs.
